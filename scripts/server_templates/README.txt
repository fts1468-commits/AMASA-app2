AMASA | منصة إدارة وحجوزات الشاليهات والاستراحات
حزمة الإنتاج الجاهزة للتشغيل والاستضافة المباشرة (Production Build)
========================================================================

هذه الحزمة مترجمة ومبنية بالكامل جاهزة للعمل فوراً (Zero Dependencies):
- لا تحتاج إلى تنفيذ `npm install` على الإطلاق.
- لا تحتاج إلى اتصال بالإنترنت أو بمستودع npmjs.org.
- لا تحتاج إلى تشغيل `vite build`.

------------------------------------------------------------------------
طرق التشغيل الفوري في أي بيئة (مثل /home/claude/ أو أي سيرفر):
------------------------------------------------------------------------

1) باستخدام Node.js مباشرة بدون أي مكتبات خارجية:
   node serve.cjs
   أو:
   node serve.mjs
   (سيفتح التطبيق على http://localhost:3000)

2) باستخدام Python مباشرة بدون أي مكتبات:
   python3 serve.py
   أو:
   python3 -m http.server 3000

3) أو النشر المباشر (Static Hosting):
   قم برفع محتويات هذا المجلد مباشرة إلى أي استضافة تدعم المواقع الثابتة
   (Nginx / Apache / cPanel / Vercel / Netlify / Cloudflare Pages / GitHub Pages).

------------------------------------------------------------------------
محتويات المجلد:
------------------------------------------------------------------------
- index.html: الصفحة الرئيسية للتطبيق
- assets/: ملفات JavaScript و CSS المترجمة والمضغوطة
- serve.cjs: سيرفر محلي خفيف عبر Node.js بدون اعتمادات
- serve.mjs: سيرفر محلي خفيف عبر Node.js (ES Module)
- serve.py: سيرفر محلي خفيف عبر Python3 بدون اعتمادات
